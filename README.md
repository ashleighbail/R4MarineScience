# Module 1: R for Data Science
### Workshop 1 – Foundations of Data Science

This workshop introduced foundational data wrangling, summarisation and
visualisation in R. Using the Palmer Penguins dataset, the analysis explored
patterns in penguin body mass across species and islands and compared
standard deviation and standard error as measures of variation and uncertainty.

**Workshop files**

- `code/Workshop1.R` – R analysis and data-wrangling workflow
- `docs/workshop1.qmd` – Quarto document used to produce the workshop report
- `outputs/` – Exported tables, figures and R data objects
